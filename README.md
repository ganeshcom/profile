# Ganesh T — Animated GitHub Pages Portfolio

This folder is ready to upload to a GitHub repository and publish with GitHub Pages.

## 1) Files
- `index.html` — all 8 slides/sections and direct links.
- `style.css` — all layout, animation and colours.
- `script.js` — theme switching, light blink/sparks, mouse tracker, active section and scroll progress.
- `assets/` — your portfolio images, including the visitor card.

## 2) Fast GitHub Pages setup
1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.
6. GitHub will give you the published site link.

## 3) Change colours
You can change colours without editing the layout:
- Click **Theme** in the top-right of the site and choose Crimson / Ocean / Lime / Violet / Mono.
- Use **Custom accent** for any colour.
- For permanent manual edits, open `style.css` and change the variables at the top of `:root`.

## 4) Change text / links
Everything is inside `index.html` and is labelled by slide number.
The internship Drive link and Google Form link are already added as direct clickable links.

## 5) Replace images
Put new images inside `assets/` and update only the `src="..."` paths in `index.html`.

## 6) Visitor card
The visitor card is taken from the uploaded portfolio document and is available on Slide 7. The **Download visitor card** button downloads the image directly.

## Design features included
- 8 full-screen sections
- Animated neon gradient background
- Mouse-follow cursor ring

- Scroll progress bar
- Section navigation 01–08
